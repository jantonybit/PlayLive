# PlayLive

Player de áudio ao vivo controlado por teclado e MIDI.

- **40 slots** — 2 abas (Aba A / Aba B) × 20 pads, com mixagem independente
- **Teclado** — setas navigam, `Enter` toca, `Tab` troca de aba, `Espaço` para, `F11` tela cheia
- **MIDI** — Learn automático para pads, STOP, troca de aba, volume e balance
- **Ações pós-término** — Parar, Loop, Próximo ou Selecionar destino
- **Fade-out e crossfade** configuráveis
- **Cenas** — salvar, importar e carregamento automático da última cena

O botão esquerdo do mouse não dispara faixas, por decisão de projeto: evita
acionamentos acidentais durante a performance.

## Requisitos

- Windows 10 (1809+) ou Windows 11, x64
- 2 GB de RAM livres
- Saída de áudio do Windows
